# Decision — M008 communication scope (2026-10-08)

## Accepted scope (from arch M008, kept minimal)
`sim/comms` owns messages + one compound group. DM commands (`dm_tell`,
`dm_request`), group chatter driven by world-event reactions, structured
chat responses via a pure `draft_action` query (returns a verb Command for the
caller to dispatch normally — no nested dispatch, no resolver duplication),
`query.chats()`, derived/capped `query.notifications()`, `query.book()`
(compound public memory), overhearing as membership witnessing, and small
co-presence rumour spread as weaker hearsay beliefs (same `origin_id`).

## Deliberate reductions (with reasons)
- No additional groups (arch forbids), no voice/media/free text (arch forbids).
- `dm_request` creates no favour obligation (unlike Ask): chat requests stay
  informal pre-commitments; the favour cost belongs to the formal Ask path.
  Documented in code, tested.
- Overhearing = group membership witnessing, not per-message eavesdrop rolls:
  deterministic and explainable; M009 places will refine co-presence.
- Rumour spread only creates beliefs where none exists (never overwrites),
  one certainty step down, same origin_id — the weakest honest version.
- Chatter fires only on enumerated world events from content rules; unknown
  event kinds fail closed (no chatter) rather than inventing content.
