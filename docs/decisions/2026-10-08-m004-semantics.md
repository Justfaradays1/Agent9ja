# Decision — M004 locked semantics (2026-10-08)

No architecture change. These close ambiguities using the smallest semantics
that satisfy the milestone. All are tested.

- Disclosure = rule disposition → stance downgrade (Burned/Frosty) →
  incentive-conflict downgrade (tag overlap) → outcome. Downgrades only ever
  conceal (tell→shade→deflect→refuse); mislead comes solely from an explicit
  authored rule WITH false_value, else degrades to deflect (never invents).
  Deferred inputs (amount spent, listeners, confidence obligations) are
  documented hooks in sim/knowledge, not silent defaults.
- Every ask creates an implicit Favour obligation (due 7d, grace 3d slice
  defaults), even when refused — attention is the price (arch §8.8).
- Promise = template-bound create_obligation sharing obligations' builders
  (no duplicated rules). Repay = settle_obligation via shared settle builder.
  Vouch creates a contingent record only; settling it refuses loudly until M005.
- Requests live in the obligations module (pre-commitment family, separate
  store); Decline is target-only; fulfillment deferred to M005+.
- Claims are append-only + supersede-on-rehear; no expiry in M004
  (documented). Cards count distinct origin_ids; show only learned incentives.
- Person views exclude incentive tags (leak test enforced). Debug truth lives
  behind a non-query accessor (`debugInspect`) used by console `--truth` only;
  tests assert its absence from the query surface.
- Menu lists verbs, never topics anyone knows; repay/decline availability
  derive from live obligations/requests state.
