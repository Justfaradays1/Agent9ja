# Decision — M005 memory & consequence semantics (2026-10-08)

No architecture change. These lock ambiguities the arch left open.

- Memory kinds shipped: broke_promise / was_owed_broken (scars) + was_repaid.
  Every kind is gate-consumed (lint-enforced); anything else fails the build.
- Gates: disclosure downgrade (burn scar, cited), disclosure upgrade
  (clean repay; Shade/Deflect only — rule Refuse/Mislead stand), vouch refusal
  (burn cited, no silent scoring), grace halving (floor, cited on record).
  Downgrades only ever conceal; mislead comes solely from authored rules.
- Retention: per-person cap 50 on NON-SCARS, evict lowest (salience, seq);
  scars exempt + permanent. Total growth bounded by journal × rules in practice;
  scar-count pressure is an M006 revisit, documented in-module.
- Journal ≠ memory: formation only for direct participants via content rules;
  no hearsay transfer until M008 comms. Third parties provably form nothing.
- Duplicate-safe by construction: deterministic mem_<seq>_<person>_<kind> ids
  + applier skip-if-exists. Double wiring of consequence mapping throws.
- Seeds: store + fire-in-(fire_t,id)-order + cancel + cap 100 + restore-safe.
  No consumers yet (storylets M007) — documented machinery, not a feature.
- Favour derivation stays 0: favour obligations exist and settle, but standing
  still derives from relationships only until verbs consume the ledger (M006+).
- what_they_remember exposes kinds+subjects+times only; full records live
  behind a non-query debug accessor (absence tested on the query surface).
- Repairs folded in: seen-table eviction is lowest-firstSeq (M003 follow-up);
  verbs/tests now always pass memoryReads (no silent gate-skipping).
