# Decision — Node version drift + M000 baseline (2026-10-08)

## Node drift: RESOLVED as floor, not pin
- Dev machine runs Node 25.2.1; locked target was "Node 20 LTS".
- Decision: `engines: >=20`. Node:test API used by M000 runner is stable
  since v18; no dependencies exist, so drift surface is ~zero.
- `npm test` verified green on 25.2.1 at M000 baseline.
- If a future dependency requires a narrower range, pin then. No toolchain
  change justified now (smallest-thing rule).

## TS vs JS: DEVIATION RECORDED (not hidden)
- Architecture §19.1 locks TypeScript. M000+M001 implement in JS ESM with
  JSDoc types and frozen read views.
- Rationale: zero build step keeps headless tests one-command and reviewable;
  behavior contracts (determinism, ordering, idempotency) are identical.
- Migration trigger: strict `tsc` at M006 schema freeze. If M001–M005 stay
  green in JS, migration is mechanical (rename + types), not architectural.

## Git baseline
- Repo initialized; `.gitignore` excludes node_modules/builds/dist/coverage/
  test-results/logs/.env/saves/*.local.json/OS-editor/tmp.
- `builds/` ignored per architecture §6 (regenerable output).
- `assets/`, `assets_src/` versioned; `.gitattributes` tracks only true
  large binaries (*.blend/*.fbx/*.ma/*.mb/*.psd/*.xcf/*.exr/*.tif/*.wav/*.aif).
  Small ship files stay in Git until measured otherwise.
- Identity used inline (`-c`) so no global git config was changed.
- Baseline: commit `M000: project foundation…` + tag `M000`. Empty skeleton
  dirs are untracked (git limitation); structure fills in from M001.
